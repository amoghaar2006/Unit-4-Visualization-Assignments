## Assignment Details

### PPT 3 – LLMs for EDA and Human-in-the-Loop Visualization

**Dataset:** `freshkart_orders.csv`

This assignment explores how Large Language Models can assist with exploratory data analysis and visualization.

Topics covered:
- Data profiling and quality checks
- Exploratory data analysis
- Histograms and distribution analysis
- Trends and correlation analysis
- Store clustering and hypothesis testing
- Evaluating AI-generated insights
- Human validation and responsible use of AI

Files:
- `Unit4_ppt3demo.ipynb`
- `Unit4_ppt3activity.ipynb`

### PPT 4 – AI-Assisted Pattern and Anomaly Visualization

**Dataset:** `freshkart_coldchain.csv`

This assignment explores anomaly detection and visualization in cold-chain monitoring.

Topics covered:
- Data abstraction and visual encoding
- Distribution analysis and histogram bin widths
- Z-score and IQR-based outlier detection
- Precision, recall, F1-score and confusion matrix
- Threshold selection and cost evaluation
- Contextual and collective anomalies
- Visual emphasis and anomaly interpretation
- Standard deviation versus standard error

Files:
- `Unit4_ppt4demo.ipynb`
- `Unit4_ppt4activity.ipynb`

## How to Run the Notebooks

1. Clone this repository:

   ```bash
   git clone https://github.com/amoghaar2006/Unit-4-Visualization-Assignments.git
   ```

2. Navigate to the repository:

   ```bash
   cd Unit-4-Visualization-Assignments
   ```

3. Install the required Python libraries:

   ```bash
   pip install pandas numpy matplotlib scipy scikit-learn jupyter
   ```

4. Launch Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

5. Open the required notebook from the respective PPT 3 or PPT 4 folder.

6. Ensure the corresponding CSV dataset is present in the same folder as the notebook before executing the cells.
